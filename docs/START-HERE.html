Design Lens / Chrome & Edge

Install your design toolkit.

Pick live components, collect tokens and styles, save image references, and export a complete bundle for your coding assistant. No account, backend, or API key.

Installation candidate. Local checks passed, but native browser-extension and axe tests remain unverified. GitHub publication was blocked. The full source ZIP contains the implementation and tests; read docs/DELIVERY.md for the boundary.

Load the extension

  1. Extract the installation ZIP into a permanent folder.
  2. Open edge://extensions or chrome://extensions.
  3. Enable Developer mode and choose Load unpacked.
  4. Select the extracted edge-design-capture folder containing manifest.json. From the source ZIP, select its extension folder instead.
  5. Pin Design Lens in the toolbar. Open a normal website and click the icon, or press Alt+Shift+D.

Capture a real component

Pick element → Parent → Capture component → Scan page → Download complete bundle. Use Parent to capture the whole card or section rather than just its label. The ZIP combines a reconstruction brief, HTML/CSS/TSX, tokens and any reference PNG.

Capture a screenshot reference

On Mobbin or another image gallery, use Capture → Select area or import an image. The PNG and sampled palette are references, not the pictured app’s original source. Attach the PNG alongside Copy for Codex.

Keep the boundary clear

Only tabs you explicitly grant access are inspected. Screenshots and visible text may still be private; review before sharing. Script-free exports are a static starting point, not original React logic or automatic responsive behavior. No source font files are included.

Get unstuck

Esc or Stop cancels picking. Click the toolbar icon again after navigating to a new site. Keep the extracted folder in place. Export saved references before uninstalling. Do not change organizational browser policies to install it.

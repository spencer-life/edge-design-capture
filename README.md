# Edge Design Capture

Local-first design inspection and component capture for desktop Chrome and Microsoft Edge.

The initial implementation is tracked in [issue #1](https://github.com/spencer-life/edge-design-capture/issues/1). Application code and validation will arrive on a focused pull request.

Workflow baseline: [spencer-life/project-template](https://github.com/spencer-life/project-template), especially `docs/git-workflow.md`. Keep coherent commits, run relevant checks, and require specific user approval before merging a PR.
